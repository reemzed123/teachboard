# TeachBoard

סביבת הוראה דיגיטלית למורים: לוח כתיבה, מחברת שיעורים, מתמטיקה, גיאומטריה דינמית ו-PDF – בעברית, ועובדת גם ללא אינטרנט.

> תוכנה בקוד סגור. כל הזכויות שמורות.

## מצב הפרויקט

ראו [`docs/STATUS.md`](docs/STATUS.md). התוכנית המלאה: [`docs/PLAN.md`](docs/PLAN.md). החלטות: [`docs/decisions/`](docs/decisions/).

## פקודות למפתחים

```bash
pnpm install        # התקנת ספריות
pnpm dev            # הרצה לפיתוח
pnpm check          # כל הבדיקות: טיפוסים, קוד, עיצוב, בדיקות, רישיונות, בנייה, דפדפן
```
