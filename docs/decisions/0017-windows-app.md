# 0017 – תוכנת Windows (שלב 9)

סטטוס: **מומש – ממתין לבדיקה במחשב של הבעלים** (2026-11-26).
הבעלים אישר: Tauri 2, **בלי חתימה דיגיטלית**, עדכון בהורדה והרצה של קובץ ההתקנה החדש.

## איך זה בנוי

- **Tauri 2** (רישיון MIT/Apache): חלון Windows שמציג את אותה תוכנה בדיוק כמו בדפדפן, דרך WebView2 (רכיב התצוגה של Microsoft, Chromium). אין שכתוב – קוד אחד לשתי הגרסאות.
- קוד ה-Rust מינימלי (`src-tauri/src/lib.rs`): רק פתיחת קובץ ‎.board שאיתו הופעלה התוכנה. בלי גישה כללית לקבצים או לרשת (הרשאות `core:default` בלבד).
- **מדיניות אבטחה מחמירה (CSP)**: רק קבצים מתוך התוכנה; לא נטען שום דבר מבחוץ ולא מורץ קוד מקבצים. בדיקה אוטומטית מריצה את התוכנה בדפדפן עם אותה מדיניות ומוודאת שאין חסימות (נוסחאות, גיאומטריה, PDF).
- **קובץ התקנה NSIS**, למשתמש הנוכחי (בלי הרשאות מנהל), עברית ואנגלית. WebView2 מותקן אוטומטית אם חסר.
- **שיוך קבצים**: ‎.board נפתח ב-TeachBoard. PDF – לא משויך (כדי לא להחליף את תוכנת ה-PDF של המחשב); פותחים PDF מתוך התוכנה.
- **מזהה קבוע** `com.teachboard.app` – לא לשנות: לפיו Windows שומר את השיעורים, ושינוי שלו "יאבד" אותם בעדכון.
- גרסה: `package.json` (כרגע 0.9.0) – מוצגת בהגדרות.

## בנייה

GitHub Actions (`.github/workflows/windows.yml`) על מחשב Windows: בכל שינוי ב-main – קובץ התקנה להורדה (30 יום); בתגית `v*` – Release קבוע. אין צורך בכלי פיתוח במחשב של הבעלים.

## עדכונים

מורידים ומריצים את קובץ ההתקנה החדש – מעדכן במקום, השיעורים נשארים. גרסאות קודמות נשארות ב-Releases לחזרה אחורה. עדכון אוטומטי מתוך התוכנה – אפשרי בהמשך, אחרי שהגרסה הבסיסית תוכח במחשב של הבעלים.

## לא מובטח לפני בדיקה אמיתית

לחץ עט ודחיית כף יד ב-WebView2 עם Huion H580X – נבדק במחשב של הבעלים (רשימה ב-docs/INSTALL-WINDOWS.md).
