# 0008 – התנהגות קלט (עט, עכבר, מגע) וקיצורי מקלדת

סטטוס: **מומש בשלב 2** (2026-11-25). כללים שנקבעו כברירת מחדל – ניתן לשנות לפי ניסיון בכיתה.

## עט

- לחץ העט משנה את עובי הקו (עט בלבד, לא מדגיש). אפשר לכבות בחלונית "ציור וכתיבה".
- אם העט לא מדווח לחץ (למשל Huion בלי Windows Ink) – הקו בעובי קבוע, והחלונית מציגה הסבר.
- קצה המחק של העט (אם יש) מוחק זמנית, בלי להחליף כלי.
- הקו שנכתב מצויר על משטח מהיר נפרד, עם "חיזוי" של המשך התנועה, להקטנת תחושת ההשהיה.

## מגע

- שתי אצבעות: זום והזזה (צביטה).
- אצבע אחת: מציירת – **עד שמזוהה עט**. מרגע שזוהה עט, אצבע אחת רק מזיזה את הלוח (מונע ציור לא רצוי בכף היד במסכי מגע).

## עכבר ומשטח מגע של מחשב נייד

- גלגלת: גלילה. Shift+גלגלת: גלילה לצדדים. Ctrl+גלגלת (או צביטה במשטח): זום סביב העכבר.
- לחצן אמצעי, או החזקת רווח: הזזת הלוח.

## קיצורי מקלדת

פועלים גם כשהמקלדת על עברית (לפי מיקום המקש). אפשר למפות אליהם את לחצני ה-Huion בדרייבר.

| מקש                   | פעולה                                                |
| --------------------- | ---------------------------------------------------- |
| P                     | עט                                                   |
| M                     | מדגיש                                                |
| E                     | מחק                                                  |
| V                     | בחירה                                                |
| H                     | הזזת הלוח                                            |
| רווח (החזקה)          | הזזה זמנית                                           |
| Ctrl+Z                | ביטול                                                |
| Ctrl+Y / Ctrl+Shift+Z | ביצוע חוזר                                           |
| Delete / Backspace    | מחיקת הבחירה                                         |
| Ctrl+A                | בחירת הכול                                           |
| Ctrl+= / Ctrl+-       | הגדלה / הקטנה                                        |
| Ctrl+0                | התאמת התוכן למסך                                     |
| Escape                | ביטול בחירה / יציאה ממצב הסתרת סרגלים / סגירת חלונית |

## מראה

הלוח עצמו נשאר לבן גם במצב כהה (כמו דף), כדי שצבעי הכתיבה ייראו נכון. צבעי רקע ללוח – בשלב 3.
