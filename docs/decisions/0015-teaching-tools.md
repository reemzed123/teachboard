# 0015 – כלי הוראה (שלב 7)

סטטוס: **חלק א מומש** (2026-11-26). רשימת הכלים – מהאפיון המקורי, סעיפים 10 ו-17; הבעלים אישר להמשיך ("קדימה").
תבניות וספריית חומרי לימוד – **לא נבנים** (החלטת הבעלים).

## חלק א – כלים לזמן השיעור (לא נשמרים בשיעור)

| כלי          | איך          | הערות                                                                                                             |
| ------------ | ------------ | ----------------------------------------------------------------------------------------------------------------- |
| מצביע לייזר  | כלי בלוח (K) | נקודה אדומה זוהרת; בלחיצה – שובל שדועך תוך כשנייה. לא נכתב כלום ולא נכנס להיסטוריית הביטול.                       |
| זרקור        | לחצן         | הלוח מוחשך חוץ מעיגול סביב העט. לא חוסם – אפשר לכתוב בתוך האור. גודל: מחוון או Alt + גלגלת. Esc סוגר.             |
| כיסוי וחשיפה | לחצן         | "וילון" מלמעלה/למטה/ימין/שמאל; גוררים ידית (או חצים במקלדת) לחשיפה הדרגתית. האזור המכוסה לא מקבל כתיבה. Esc מסיר. |
| טיימר        | לחצן         | 1/3/5/10 דקות או מספר דקות לבחירה; התחלה, עצירה, איפוס; בסיום – הודעה, הבהוב וצליל קצר (נוצר בקוד, אפשר להשתיק).  |
| שעון עצר     | לחצן         | סופר למעלה; אותו חלון.                                                                                            |
| מצב הצגה     | לחצן         | מסתיר את כל הסרגלים (היה קיים מהשלב הראשון; עכשיו גם בחלונית). הטיימר נשאר גלוי.                                  |

- הזמן מחושב לפי שעון אמיתי ולא לפי מספר העדכונים במסך – מדויק גם כשהמחשב עמוס.
- כל הכלים זמינים גם כלחצני גישה מהירה (בהגדרות).
- חלון הטיימר ניתן לגרירה לכל מקום על הלוח.
