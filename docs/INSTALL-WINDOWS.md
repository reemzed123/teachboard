# התקנת TeachBoard ב-Windows

## הורדה

1. נכנסים לדף המאגר ב-GitHub ← **Releases** (בצד ימין של הדף הראשי).
2. בגרסה האחרונה מורידים את הקובץ שמסתיים ב-‎`-setup.exe`.

(גרסה מכל שינוי אחרון נמצאת גם ב-**Actions** ← "Windows app" ← הריצה האחרונה ← **Artifacts**. זה קובץ ZIP שבתוכו קובץ ההתקנה.)

## התקנה

1. פותחים את קובץ ההתקנה.
2. Windows עשוי להציג **"Windows protected your PC"** (התוכנה לא חתומה דיגיטלית – כפי שהוחלט). לוחצים **More info** ← **Run anyway**.
3. ההתקנה היא למשתמש הנוכחי בלבד, בלי הרשאות מנהל.
4. אם חסר במחשב רכיב התצוגה של Microsoft (WebView2) – ההתקנה מורידה אותו לבד. ב-Windows 11 הוא כבר קיים.

אחרי ההתקנה: TeachBoard בתפריט התחל, וקובצי ‎.board נפתחים בה בלחיצה כפולה.

## עדכון לגרסה חדשה

מורידים את קובץ ההתקנה החדש ומריצים אותו – הוא מעדכן את התוכנה הקיימת.
**השיעורים לא נמחקים** בעדכון (הם שמורים בתיקייה נפרדת במחשב). לביטחון נוסף – אפשר לשמור גיבוי כקובץ ‎.board.
אם משהו לא תקין בגרסה חדשה – מתקינים שוב את הגרסה הקודמת מ-Releases.

## העברת שיעורים מהדפדפן

השיעורים בדפדפן ובתוכנה המותקנת נשמרים בנפרד. להעברה: בדפדפן ← "שמירה כקובץ שיעור", ובתוכנה ← "פתיחת קובץ שיעור" (או לחיצה כפולה על הקובץ).

## רשימת בדיקה ראשונה (על המחשב שלך, עם ה-Huion H580X)

- [ ] התוכנה נפתחת, במסך מלא, בעברית.
- [ ] כתיבה בעט: חלקה, בלי השהיה, בלי קטיעות; לחץ העט משנה עובי (אם הלוח מדווח לחץ).
- [ ] ריחוף העט מעל הלוח מזיז את מצביע הלייזר.
- [ ] נוסחה, גרף, בנייה גיאומטרית – נוצרים ונראים חדים.
- [ ] פתיחת PDF, כתיבה עליו, ייצוא PDF – הקובץ נשמר ונפתח.
- [ ] שמירה כקובץ שיעור ופתיחה בלחיצה כפולה ב-Windows.
- [ ] סוגרים את התוכנה ופותחים שוב – השיעור האחרון חוזר.
- [ ] ניתוק אינטרנט – הכול ממשיך לעבוד.
